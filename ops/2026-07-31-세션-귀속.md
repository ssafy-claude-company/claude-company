# 세션 귀속 — 어느 세션이 무엇을 했는가 (2026-07-31, 현준-4)

## 무엇이 문제였나

sudo 로그는 행위자를 전부 `dojin`으로 남긴다. 세션이 여럿 도는데 전부 같은 계정이라
서버에서 벌어진 일을 세션 단위로 되짚을 수 없었다.

TTY로 가를 수도 없다. 실측한 로그 줄은 이렇다.

```
sudo[2986367]: dojin :  PWD=/home/dojin ; USER=root ; COMMAND=/usr/bin/journalctl
```

`dojin :` 뒤 TTY 칸이 비어 있다. Claude Code의 명령이 제어 터미널 없이 돌기 때문이다.
살아 있는 프로세스를 보면 pts와 세션 이름이 짝지어지지만(pts/4 → 현준-1), 로그에 TTY가
안 남으니 사후에는 이을 수 없다.

봇 쪽 감사는 살렸는데 사람 쪽은 여전히 깜깜했다.

## 어디서 잡나

명령이 실행되기 직전이다. 세션 이름은 자기 조상 프로세스(`claude --name`)가 알고 있으므로,
훅이 조상 사슬을 거슬러 올라가 이름을 찾아 기록에 함께 남긴다. sudo를 감싸지 않는다 —
감싸면 sudo만 잡히고 나머지가 빠진다.

## 기록의 무결성

기록 파일은 append-only다.

```
chattr +a /var/log/claude-session-audit.jsonl
```

세션은 dojin 권한으로 덧붙일 수만 있고 지난 줄을 고치거나 파일을 지울 수 없다(실측: 덮어쓰기
`Operation not permitted`, 삭제 차단). 속성을 벗기려면 CAP_LINUX_IMMUTABLE이 필요하다.

## 설치

1. 기록 파일을 만들고 append-only로 잠근다.

```
sudo touch /var/log/claude-session-audit.jsonl
sudo chown dojin:dojin /var/log/claude-session-audit.jsonl
sudo chmod 0644 /var/log/claude-session-audit.jsonl
sudo chattr +a /var/log/claude-session-audit.jsonl
```

2. 훅을 설치한다. `/root` 아래는 dojin이 못 들어가므로 레포가 아니라 실행 경로에 둔다.

```
sudo install -m 0755 ops/hooks/claude_session_audit.py /usr/local/bin/claude-session-audit
```

3. `~/.claude/settings.json`에 PreToolUse 훅을 등록한다. **이 단계는 사용자 승인이 필요하다** —
   그 파일은 이 기계의 모든 세션에 함께 걸린다.

```json
"hooks": {
  "PreToolUse": [
    { "matcher": "Bash|Write|Edit",
      "hooks": [{ "type": "command", "command": "/usr/local/bin/claude-session-audit" }] }
  ]
}
```

## 설계에서 지킨 것

- 훅은 무슨 일이 있어도 0으로 끝난다. 기록은 관측이지 관문이 아니다 — 여기서 막히면
  사람의 작업이 멈춘다. 깨진 입력·빈 입력·기록 실패 모두 실측으로 확인했다.
- 명령 원문은 그대로 남긴다. 무엇을 했는지가 기록의 전부다. 다만 한 줄이 로그를 삼키지
  않도록 2000자에서 자른다.
- 조상 사슬은 12단계까지만 거슬러 오른다. 이름을 못 찾으면 null로 남기고 넘어간다.

## 로테이션

append-only라 보통의 로테이션(rename + 새 파일)이 실패한다. 속성을 잠깐 벗기고 돌린 뒤
곧바로 다시 건다 — root만 할 수 있다(CAP_LINUX_IMMUTABLE). 설정은
`ops/hooks/logrotate-claude-session-audit.conf`이며 `/etc/logrotate.d/`에 설치한다.

회전본은 root 전용 읽기(0400)로 못박는다. `copytruncate`는 소유자를 그대로 물려주는데,
그러면 세션(dojin)이 지난 기록을 고칠 수 있다 — 살아 있는 파일만 잠그고 지난 것을
열어두면 잠근 의미가 없다.

실측(강제 회전): 회전본 35,747바이트 보존 · 새 파일에 `a` 속성 재적용 · append 정상 ·
덮어쓰기 `Operation not permitted` · 회전본 수정 `Permission denied`.

## 남는 것

- 세션 이름은 사람이 정한 문자열이라 위조 가능하다. 같은 계정 안에서의 구분이지
  권한 경계가 아니다. 계정을 나누지 않는 한 이 이상은 안 된다.
